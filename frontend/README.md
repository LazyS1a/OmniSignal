# Omni 广告素材工作台前端

React + TypeScript + Vite。构建后由工作台 FastAPI 在 `/workbench/` 同源提供页面与 API。页面不保存管理员 API Token；登录使用服务端账号、HttpOnly 会话 cookie 和 CSRF 校验。

```powershell
cd frontend
npm ci
npm run build
```

构建产物位于 `frontend/dist/`，不提交到 Git。Node.js 需要满足 Vite 8 的版本要求；本次构建使用 Node.js 24。Python 工作台启动与账号初始化见项目根目录说明。

开发时使用 `npm run dev`；开发服务器把 `/workbench/api` 代理至 `127.0.0.1:8010`。请先在对应端口启动后端，不要把开发服务器暴露到公网。生产环境使用 FastAPI 提供构建产物。

## 页面与交互

- 素材库：默认展示已收录素材，广告和设计参考都可收录；只有广告需要品牌广告或促销与转化用途，设计参考无需伪装为广告。补充参考与已排除单独选择。图片保持完整比例，支持搜索、分页、详情和发布前确认。
- 待处理：逐图核对标题、品牌、用途、内容类型、理由与来源。管理员有依据时才能修改展示、模型分析、导出权限。收录不是授权。
- 采集：创建默认暂停的计划，分开显示启用状态、配置检查和最近结果；每日请求上限有明确单位与重置时间。来源目录区分已验证与候选来源。
- 设置：模型配置状态、worker 状态、旧素材迁移、发布记录；内部测试与研究来源仅管理员可见。
- 分析建议：只有配置就绪、模型额度可用、图片分析权限已允许才可主动提交。过期建议不能采用；采用只填表，不自动审核。
- 人工审阅：中文摘要和八项设计分析分别可编辑，每项明确标注视觉观察或分析推断。人工逐项核对并勾选确认后，保存操作才会提交审核版；修改分析表单会取消确认。既可采用有效模型任务的草稿，也可独立手写。服务端绑定素材版本、图片哈希和审核人；普通编辑会使旧审核版过期，界面明确显示需要重审。
- 撤回：管理员填写原因并确认后发送撤回通知。签名包发布与下游接收分别呈现。

## 验证边界

`npm run build` 同时执行 TypeScript 类型检查和生产构建。页面无内置演示素材或伪造业务数据。浏览器验收应使用隔离数据库与明确标注的合成测试图；合成图用于验证交互，不可作为真实广告分类准确率证据。

覆盖登录、真实空态、图片导入、审核收录、素材筛选、计划创建、只读权限、设置、退出与窄屏。网络错误显示可行动提示，不用测试夹具填补空白。

人工审阅回归还验证：设计参考不填广告用途也能收录；中文摘要与八项依据字段实际落库；重新打开不丢失；普通编辑使审核版过期；显式重新确认绑定新的素材版本。模型展示测试使用明确标记的合成响应，只验证展示，不伪造有效模型任务或触发收费调用。

### 可复跑浏览器回归

```powershell
npm ci
npx playwright install chromium
# 指向已安装本项目 Python 依赖的解释器；也可省略以使用 PATH 中的 Python。
$env:SMOKE_PYTHON = '你的虚拟环境/Scripts/python.exe'
npm run test:smoke
```

默认自动创建临时数据库、随机测试账号、合成图和回环地址上的 API 服务，执行结束后关闭服务并清理临时数据。采集 worker 与模型调用关闭，计划保持暂停。截图和结果写入忽略提交的 `frontend/test-results/`。安装了 Google Chrome 时，可以设置 `SMOKE_BROWSER_CHANNEL=chrome` 使用本机浏览器。

也可指定 `SMOKE_BASE_URL`、`SMOKE_USERNAME`、`SMOKE_PASSWORD`、`SMOKE_IMAGE_FILE` 连接现有**隔离测试环境**。该模式只允许回环地址，合成图片路径必须显式给出；会留下测试素材和暂停计划，不要连接日常使用的数据目录。默认临时服务模式会额外验收只读角色权限。

# 来源页评审与广告版的整合

2026-10-23。评审作为问题线索，操作行为以代码、测试和真实来源验证为准。原评审面向无操作员身份的旧控制台，不能由此断言所有角色都缺少操作入口。

| 原问题 | 本版处理 | 验证 |
| --- | --- | --- |
| 首次进入不知道从哪里开始 | 图片库作为首页；导入/采集计划两个入口；存在待处理时明确引导 | 浏览器空态、导入审核测试 |
| 开关、就绪和运行混为一谈 | 配置结果、启停、上次运行独立；未检查连接不等同可连通 | API与计划浏览器回归 |
| 全部旧来源未运行，被误读系统没采集 | 新采集直接写工作台计划与素材；旧研究/测试来源仅在诊断标明历史未接入 | 状态接口及来源分类 |
| 无权限时界面像坏了 | 登录角色明确，只读操作禁用并解释；后端仍拒绝越权 | viewer浏览器、API角色/CSRF测试 |
| 大量技术说明压过图片 | 三主入口；配置、模型、迁入与历史记录归设置；完整比例缩略图 | 桌面/手机截图与无横向溢出检查 |
| 全是空值，没有下一步 | 区分尚无运行、执行器未启动、缺模型配置、候选来源未验收 | 空库与禁用状态测试 |
| 花费不可知 | 展示真实请求额度与已用数；每个HTTP请求前原子预留；模型独立日限额 | 并发预算、失败扣额、显式重试测试 |
| 失败只能翻日志 | 计划展示失败原因及对应动作；不泄露完整异常或凭据 | 来源拒绝、暂停、预算耗尽、结构变化测试 |
| 测试夹具混入真实数据 | 生产素材无自动种子；测试运行临时SQLite/合成图；夹具属于管理员诊断 | 浏览器真实空态与测试隔离 |
| 来源字段被当永久授权 | 导入用途均为未知；管理员记录依据；发布需展示/导出允许 | 未知权限阻断发布测试 |
| 发布与接收混淆 | 签名包生成和下游接收分别记录；无真实回执保持未确认 | 协议接收器离线验证与API结果 |
| 本地撤回被当下游已清除 | 显式签名永久撤回；消费方须先处理撤回清单；原包保持不可变 | 撤回签名、失败不改库、重启对账测试 |

本版没有照搬“所有来源都强制填写授权到期”“按满速运行换算预计账单”“在来源页塞满所有管理按钮”等建议。授权期限依具体依据记录；费用需实际计费规则与用量；页面围绕任务组织。

仍需分别验收：50张真实标注广告/反例样本、两类广告相关性指标、实际模型效果与费用、独立下游应用的现场接通及回执。它们不由功能按钮或合成图测试证明。

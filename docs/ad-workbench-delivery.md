# Omni 广告工作台首轮交付报告

验收日期：2026-10-23。对应分支：`variant/ad-workbench`。

本轮将广告工作台方案与来源页可用性评审合并实施。主要流程为：采集或导入 → 待处理 → 人工判断广告类型、用途与出处 → 素材库 → 有权限时生成签名知识包。

## 已交付

| 范围 | 实现与验收 |
| --- | --- |
| 前端重做 | React 独立工作台，主导航只保留素材库、待处理、采集；设置与账号独立入口。支持桌面和手机宽度、真实空态、错误反馈、图片完整展示。 |
| 广告分类 | 品牌广告、促销与转化两个用途，可多选；设计参考与广告分开审核，旧包装图不会自动算作广告。 |
| 采集管理 | 来源、计划、启停、运行结果、预算独立显示；默认暂停，执行器状态可见。HTTP 请求按 UTC 日限额实际计数，失败及图片请求也计入。 |
| 广告来源 | Ads of Brands 户外静态广告适配器已实采；BP&O、It's Nice That 保留为设计参考来源；Ads of the World 尚未通过采集验收，不自动启用。 |
| 审核与权限 | 图片、来源链接、保留理由、用途、展示/分析/导出权限、修改记录；角色控制、会话、CSRF 和版本冲突保护。 |
| 可选模型 | 独立模型配置、每日额度、缓存和重试；结果只是待确认建议，不能替代人工审核或授权。当前部署没有配置模型凭据，未产生模型调用。 |
| 发布协议 | 兼容知识包签名与校验，增量发布、签名撤回、下游独立读取凭据；实际下游接收状态明确为未确认。 |
| 运维 | 单进程容器、持久化数据、健康检查、日志轮转、备份与新目录恢复。恢复时清除会话、暂停计划。 |

## 实际验收结果

- 后端完整测试：**544 项通过**。有一条已有的 Starlette/httpx 弃用提示，不影响本轮结果。
- 前端类型检查与生产构建通过；隔离测试环境完成 **8 项浏览器流程检查**。
- 已部署的工作台通过健康检查、账号登录、素材库及待处理页面检查，检查过程中无 JavaScript 页面错误。
- 原准备区 **13 张图片**只读迁入待处理，迁移未改写旧准备区。
- 云端一次实际采集取得 **2 个项目、2 张图片**，共 **6 次 HTTP 请求**。项目为 R.S.I. — Road Safety Institute 的 IV Drinks 系列，两张图片均为 690 × 1062。
- 当前共 **15 张待处理素材、0 张已审核收录素材**。采集成功不等于审核通过，系统没有替用户确认用途权限。
- 广告计划每 24 小时检查一次，每天最多 12 次请求；旧通用设计采集进程已暂停，旧数据保留。
- 部署前备份和新版备份已保存；新版恢复到隔离目录的演练成功，未覆盖线上数据。
- 提交内容通过 Gitleaks 扫描。真实图片、登录文件、服务器配置、签名私钥及模型凭据均不属于公开仓库交付。

## 仍需外部验收的部分

1. **模型效果**：接口与任务流程已实现，真实模型尚未配置，也没有完成 50 张真实标注样本的质量评估。单元测试数量不能替代广告识别准确率。
2. **内容覆盖**：当前自动广告来源仅验证了户外静态广告；品牌广告及促销广告筛选能力存在，但本次公益广告样本不能证明两类内容覆盖充分。
3. **Nova 联调**：签名发布/撤回协议及参考消费者测试通过；实际 Nova 拉取、入库与回执仍待联调确认。
4. **访问方式**：本轮服务监听服务器回环地址，通过已有 SSH 连接转发访问；未额外开放公网入口。

## 使用顺序

登录后先打开“待处理”，查看本轮新获取的广告。打开图片详情，核对原始来源并填写类型、用途和保留理由，再决定收录、作为设计参考或排除。素材库默认只展示已审核收录内容，因此当前为空是正常状态。

采集页可查看实际运行结果、已用请求数、下次运行时间，并暂停计划。需要额外来源时先验证页面和图片适配器；不要把站点名称出现在列表中当作已验证采集成功。

运行、配置与备份命令见 [运维说明](ad-workbench-operations.md)，评审落实情况见 [可用性对照](ad-workbench-usability.md)。

# 助手整理来源记录

`reviewed_analysis.review_method` 可选，缺省为 `human`，显式 `assistant` 表示由助手整理摘要和八项设计依据，不能写成人工逐项复核。此标记不声明某个受管视觉模型真实运行，也不证明素材使用授权。

- `assistant` 必须配合 `source_job_id: null`。服务端写入 `assistant_editorial_review`、`model_version: none`，审核身份、时间、素材版本及图片哈希仍由服务端绑定。
- 原有独立人工审核和经验证的模型辅助人工审核保持兼容。有效模型任务不能与助手整理标记混用；客户端不能自填身份、模型版本或来源。
- 接口仍要求认证和 CSRF，权限变更仍只允许管理员并填写依据。助手来源标记不会自动收录、授权、分类或发布素材。
- 普通编辑后旧分析仍过期，发布前必须重新绑定当前版本和图片哈希。发布包使用 `assistant-design-review-1` 并保留来源记录，不更改 Nova 的 schema 1 或 nova-1 词表。
- 工作台展示“AI 助手整理，未经人工逐项复核”。用户在工作台逐项核对并明确勾选确认之后，可以另存为人工审核；打开素材不自动完成这一步。

概念案例的分类说明和摘要应同时写明 AI 生成、虚构项目、助手整理以及使用范围，不应混同真实品牌投放或效果数据。

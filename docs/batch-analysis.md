# 待处理图片批量分析

此功能用于先给待处理图片生成模型建议，再由编辑复核。不会自动收录、确认图片使用权限或发布到 Nova。

## 使用路径

进入 Omni 工作台的「待处理」，勾选图片或选择当前页，然后打开「批量分析」。先查看服务端预检，再确认开始。预检只读取状态，不请求模型、不计分析次数。

服务端按当前素材修订、分析使用权限和剩余额度决定哪些图片可以入队。没有分析使用依据、已排除、已分析、正在处理或需要明确重试的图片会列出原因。超出本次额度的图片也会跳过，不会自动在第二天扣费。

结果仍保留在待处理区。完成后打开图片详情，检查模型的识图、文字、分类与设计建议，确认后再保存审核结果。

## 成本和模型

通过 Nova 网关分析时使用其配置的视觉模型。Omni 和 Nova 网关分别执行各自的次数配置，以部署配置和预检显示为准。次数不是账单金额；失败请求也可能计入用量，重试需在详情中明确操作。

### 每日次数配置

Omni 的环境变量 `OMNISIGNAL_WORKBENCH_MODEL_DAILY_REQUEST_LIMIT` 支持以下值，更新部署环境后重启服务生效：

- `unlimited`：不设置 Omni 每日分析次数上限；持续记录每日调用量。接口的 `request_limit` / `quota.limit` 和 `remaining` 返回 `null`，`unlimited` 为 `true`，界面显示“无每日次数上限”。
- `1` 至 `10000` 的整数：按 UTC 日限制请求数，包含排队预留；超出次数的图片不入队。
- `0`、缺省或非法值：关闭新分析请求；不会因为漏配而启用无限模式。

无限模式仍保留单批最多 100 张、排队任务最多 100 项、逐张权限和修订校验、请求幂等以及人工确认重试。它不代表免费或绕过供应商限制。使用 Nova 网关时，还需同时核对网关的独立配置；只取消 Omni 限制不会取消网关或供应商限制。采集计划的网络请求预算与图片分析次数分别配置，不受此设置影响。

批量处理功能本身不修改 Nova 全局模型，也未接入阿里云异步 Batch 计费接口。工作台的多选排队仍逐张调用已配置接口，不因叫作批量处理就享有供应商折扣。

不同接入渠道的计费不同。通过 Nova 使用已有第三方网关时，应以该账户实际用量和账单为准，不能直接套用阿里云百炼的直连报价。批量前先用少量已授权图片检查输出质量与实际用量。

来源：[阿里云百炼模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)。该页对支持的供应商 Batch 调用注明半价，接入该接口需要独立实现异步任务提交与结果下载。

官方搜索索引仍能检索到 Qwen3-VL-Flash 的较低历史价，但其详情入口在本次核验时重定向，实时总价页未展示相同条目；本次没有把索引价当作已确认的当前开通价格。也未取得公司当前接口的实际结算单价，因此不计算虚假的节省百分比。

建议后续为灵感分析配置独立视觉模型，用相同的自有测试图比较 OCR、构图、配色、可借鉴点和事实错误率，再决定切换；不为测试直接改所有 Nova 用户使用的模型。

## 技术约束

- 仅编辑或管理员可提交；正常登录会话、CSRF 和素材修订检查仍生效。
- 批次使用稳定请求 ID；响应丢失时恢复原批次，不自动创建新付费任务。
- 单图与批量共享队列和每日次数配置；后台仍保留执行前的权限、图片完整性与配置检查。无限模式继续统计每日用量。
- 分析权限未知时保留未知，不通过批量按钮替用户声明授权依据。
- 批次进度保存于服务端；浏览器仅保存当前账号的批次标识以便恢复查看。

支持无限模式后的后端、鉴权、单图分析及人工审核集成测试共 121 项通过；有限模式批量浏览器流程 21 项、无限模式批量浏览器流程 23 项、原有浏览器回归 31 项通过，生产前端构建通过。浏览器流程采用隔离的合成图片和模拟分析提供方，未请求真实模型。部署验收记录另存于本地工作日志。

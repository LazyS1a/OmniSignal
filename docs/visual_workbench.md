# 视觉工作台

视觉工作台把“竞品视觉分析、从零创作、参考图重建、PSD 落地”拆成可替换的阶段。当前版本先提供工程骨架和稳定边界，不连接外部模型、素材站或 Photoshop。

![虚构咖啡品牌合成海报示例](assets/visual-demo-preview.png)

这是可复现的合成测试图：透明产品图、背景、氛围、装饰、标志、标题和副文案分别保存为 PNG 图层。它不是竞品样本，也不代表模型识别结果。

## 当前可用

- 在总控台创建“从零按层创作”工程。
- 无本地素材时，一键创建虚构咖啡海报示例，预览图片、查看已知图层坐标，并下载含七层 PNG 与 manifest 的 ZIP。
- 示例 manifest 记录每层 PNG 的 SHA-256；打包前核对哈希，避免导出已损坏的图层。
- 为已有工程上传单张本地 PNG；服务端限制 5 MB、4096 px 边长和 1600 万像素，解码后重新编码，记录原始与存储文件的 SHA-256、尺寸。
- 创建“参考图反向重建”工程，并登记素材使用依据、平台、公开地址或说明。
- 自动生成背景、光影、产品、装饰、Logo、标题与副文案等可编辑图层清单。
- 反向流程额外生成重建蒙版和分析证据层。
- 通过本地 API 持久化工程清单，并下载 JSON manifest。
- Docker 中写入 `/app/data/visual_projects`，实际文件由宿主机应用数据目录持久化。

普通工程创建只写元数据；点击示例按钮才会在本机合成示例图片。普通上传图目前只完成安全保存和预览，`analysis_status` 仍为 `not_requested`，不会冒充自动识别。示例图层坐标来自合成时的绘制参数，可以用来验证后续识别结果。整个过程不消耗外部模型额度，也不发起网络采集。

图片预览和 ZIP 下载要求控制身份；创建示例和上传图片要求 operator。图片与图层文件保存在项目数据目录，URL 由服务端固定生成，浏览器不能指定服务器文件路径。

## 目标链路

```mermaid
flowchart LR
    A[人工确定品类、品牌与样本边界] --> B[登记来源与使用依据]
    B --> C[视觉分析适配器]
    C --> D[结构化元素与构图证据]
    D --> E[图层规划]
    E --> F[图片生成/编辑适配器]
    F --> G[人工审核]
    G --> H[Photoshop UXP/MCP 适配器]
    H --> I[可编辑 PSD 与导出图]
```

其中：

1. **采样层**只接受明确的平台、关键词、时间窗和样本上限；抓取器不能由界面提交任意 URL、脚本或登录凭据。
2. **分析层**输出可核验的元素标签、布局、颜色、文案位置和证据引用；热度与视觉特征必须分开记录，不能把相关性写成因果。
3. **生成层**把图层规划转为生成或编辑请求。模型返回的是扁平图片时，仍需按图层分别生成、抠图或重建。
4. **Photoshop 层**只接受白名单操作，例如新建文档、置入素材、创建文字层、调整图层顺序和保存 PSD；不能透传任意脚本。

## 适配器契约

当前 `/ops/visual/capabilities` 会明确返回三个适配器的状态：

| 适配器 | 预期职责 | 当前状态 |
| --- | --- | --- |
| 图片模型 | 生成、编辑、蒙版编辑 | `not_configured` |
| Photoshop UXP/MCP | 新建文档、置入素材、文字层、排序、保存 PSD | `not_configured` |
| 竞品样本采集 | 有界采集公开样本与证据 | `not_connected` |

接入顺序固定为：先实现离线夹具与接口测试，再接测试账号，最后才允许人工触发真实调用。任何适配器失败都不得伪造成功状态。

## 边界

- 不绕过登录、验证码、付费墙、访问控制或平台限制。
- 不自动下载仅登记了链接的参考图；素材进入工程前需再次确认使用依据。
- “反向重建”表示依据可见结果重新构造图层，不表示恢复原作者的隐藏图层、字体或原始 PSD。
- 不把单张爆款图的视觉特征直接解释为爆款原因；至少需要同口径样本、曝光或互动证据和对照组。
- 不自动发布、不覆盖现有 PSD，不允许模型密钥进入工程 manifest、日志或界面缓存。

## 下一阶段验收顺序

1. 定义结构化视觉分析结果和人工复核状态，先用合成图层真值做离线验收。
2. 实现 Photoshop 适配器的模拟端，验证白名单指令与幂等保存。
3. 经人工确认后，再分别接图片模型测试账号和 Photoshop UXP 插件。

这一顺序能让主系统先稳定保存和解释工程，再逐个替换外部能力，避免把付费模型、爬虫和桌面软件同时接入后难以定位故障。

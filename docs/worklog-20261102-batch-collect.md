# Omni 批量收录开发日志 · 2026-11-02

## 需求与入口

待处理图片原来只能逐张打开详情收录。新增「待处理 → 勾选图片 / 全选本页 → 批量收录」，与批量分析共用选择，不重复增加一套勾选入口。

## 实现

- 仅前端改动，复用已有登录、CSRF 和单张收录 API。服务端逐项检查原版本，事务保存并记录实际操作人。
- 确认面板显示缩略图与分类：保留已有分类；未分类且有当前版本 AI 建议时显示建议供核对。支持统一设置为设计参考或广告素材，广告需要选择用途。
- 填写本批收录理由后提交；分类不完整、已撤回或非待处理素材明确跳过。全选只覆盖当前页，切换筛选与分页会清空选择。
- 提交时冻结图片与版本，顺序保存。版本冲突不覆盖新数据；部分成功仍能查看每项结果。双击保护、操作互斥、执行中离开页面提示、卸载停止后续请求。
- 网络异常、5xx 或不完整回执标为「结果待核实」并停止余下请求，不自动重发；401、403、429 同样停止后续提交。结果区分别统计成功、跳过、失败、待核实和未提交。
- 收录只确认状态、内容类型、广告用途和理由。展示/分析/导出权限、原图、说明与来源保持，不提交分析审核或发布分类审核，不调用模型与发布/下游接口。旧审核会随版本变化过期，确认面板明确提示。

## 保留事项

本次按当前页选择，暂不提供跨页全库收录。收录不是设计分析的逐项人工审核，也不赋予新素材展示/传输权限。自动采集、分析计划与模型配置保持原样。

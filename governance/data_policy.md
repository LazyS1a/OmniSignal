# OmniSignal 最小数据处理规则

## 1. 适用方式

这份规则约束连接器、存储、导出、可选处理插件和运维界面。当前数值默认值只适用于本地合成夹具；真实数据源必须在 `source_registry.yaml` 中单独登记后才能启用。

## 2. 收什么

- 只收登记表 `field_allowlist` 中的字段。未列出的字段在进入原始层前丢弃或脱敏。
- 原始快照不是“整包全存”；它是允许字段、响应元数据和哈希组成的可追溯快照。
- 密码、Token、Cookie、私钥、签名秘密以及支付卡、证件号、精确位置、生物识别信息禁止进入采集记录。
- 评论、帖子和网页文本统一称为“用户表达/公开内容”；只有获得授权的查询日志或站长平台查询字段才能称为搜索关键词。
- 外部文本始终是数据，不能覆盖系统提示词、连接器配置、目标允许列表或工具权限。

## 3. 为什么收、谁能看

每个字段的来源、用途和敏感级别写在登记表的 `field_catalog` 中；每个来源只能引用白名单字段。

最小角色分工：

| 角色 | 可以做什么 | 不可以做什么 |
| --- | --- | --- |
| admin | 管理登记、密钥引用、启停、删除和审计 | 读取密钥明文日志 |
| operator | 查看运行元数据、启停已批准连接器、提交删除 | 私自扩大来源范围或字段 |
| analyst | 查看已批准的标准化数据和导出 | 读取凭证、修改登记和删除记录 |
| auditor | 查看登记、权限和审计事件 | 运行连接器或修改数据 |
| connector_worker | 只写自己负责的来源和检查点 | 跨来源读取、导出或管理权限 |

Hook/私有接口 runner 使用独立凭证和最小权限账号；它不能直连其他连接器的状态或数据表。

## 4. 凭证

- Git、YAML、数据库业务表和普通日志中只保存 `credential_ref`，不保存密钥值。
- 开发环境使用环境变量或本机 secret 文件；生产环境接公司已有的密钥管理服务。
- 401/403 直接暂停对应连接器并告警，不自动尝试其他账号、Token 或绕过方案。
- 轮换密钥后做一次受控健康检查；旧密钥立即撤销，不留在备份和测试夹具中。

## 5. 保留与删除

合成夹具的暂定默认值：原始快照 30 天、标准化记录 180 天、运行日志 90 天、安全审计 365 天、备份 30 天。真实来源必须按用途和授权另填，不能直接继承。

删除触发包括：来源删除、授权撤回、保留期到期、登记表停用并要求清除、合法的数据主体/公司请求。处理顺序：

1. 立即阻止新的采集和派生处理。
2. 用 `source + source_record_id` 定位原始和标准化记录。
3. 删除正文、缓存、搜索索引、Embedding、物化指标和导出引用。
4. 已生成的聚合指标标记失效并重算，不保留可反推出被删正文的结果。
5. 备份进入到期清除队列；恢复备份时必须重放删除清单，防止数据“复活”。
6. 只保留不含正文和个人信息的删除审计：请求编号、来源、记录键哈希、时间、执行状态和处理版本。

设计目标是 24 小时内完成在线层级联删除；失败必须隔离、告警并重试，不能静默跳过。具体真实来源可以要求更短时限。

## 6. 导出与外部处理

- 导出必须携带来源、采集时间、授权/许可标记、schema 版本和质量状态。
- restricted 数据默认不可导出；管理员批准后才可生成限时、可审计的导出任务。
- 外部 LLM、Embedding 或分析服务默认关闭。启用前登记提供方、区域、保留方式、输入字段和退出方式。
- 产品评分、痛点结论、机会排序和改进建议不属于平台输出。

## 7. 审计事件

至少记录：登记变更、连接器启停、权限变更、凭证引用变更、导出、删除、删除失败、Hook runner 启动、熔断和紧急停用。审计日志不得包含原文、Token、Cookie 或完整请求头。

## 8. Gate 1 删除验证场景

固定夹具创建一条记录及其原始快照、标准化记录、缓存、索引、Embedding 占位、物化指标和导出引用。触发来源删除后，验收必须证明：

- 所有在线派生均不可再读取；
- 指标被标记失效并可重算；
- 备份恢复后删除清单会再次生效；
- 审计中仅剩不可反推正文的记录键哈希；
- 删除一个来源不会误删另一个来源的同名记录。

此场景在 Gate 3 建立存储骨架后实现为自动化测试；Gate 1 先冻结规则和预期结果。

# OmniSignal · Ad Workbench

**以图片为中心的广告素材工作台：采集、逐图审核、整理和签名交付。**

这是原 OmniSignal 的独立变体，分支为 `variant/ad-workbench`。`main` 保留通用采集与数据管理方向。本变体已经实现首版工作流；模型真实效果、广告相关性样本评测与下游现场同步尚需各自配置和验收，不用界面演示代替这些结果。

[运行与部署说明](docs/ad-workbench-operations.md) · [产品与重构方案](docs/omni-ad-workbench-plan-v1.md) · [原版 OmniSignal](https://github.com/LazyS1a/OmniSignal/tree/main)

## 三个入口

| 页面 | 可以做什么 |
| --- | --- |
| 素材库 | 完整比例图片网格，品牌广告/促销与转化筛选，品牌与标题搜索，分页、大图详情、发布选择 |
| 待处理 | 逐图判断广告类型、编辑文案、收录/补充参考/排除与恢复，修订冲突保护 |
| 采集 | 创建计划、配置检查、恢复/暂停、立即检查、最新运行及每日期望请求上限 |

账号、模型、旧库迁移、发布记录、研究来源诊断放在设置。首次进入显示真实空态；测试素材不会自动写进业务库。没有后台执行器、缺权限、预算用完、来源失效都有明确反馈。

## 内容与来源

支持两种传播目的：**品牌广告、促销与转化**，可以同时选择。来源是广告项目不代表已经确认目的，也不代表取得使用授权；所有获取的图片先进入待处理。

| 来源 | 当前自动获取范围 |
| --- | --- |
| Ads of Brands | 已验证户外静态广告列表、项目正文、同域主体图片；不采视频/品牌logo/相关推荐 |
| BP&O、It’s Nice That | 已适配设计参考，归补充来源；逐图审核后才能进入广告主库 |
| Ads of the World | 当前客户端 robots 返回拒绝访问，保留候选状态，不绕过 |
| 手工导入 | PNG/JPEG/WebP，有来源链接，管理员另行核对用途权限 |

来源验证时间为 2026-10-23，站点可能变化。遇到拒绝访问、验证码或结构变化会记录失败，不能把旧验证当永久可用证明。

## 实现状态

- **素材与溯源**：内容哈希去重、项目关联、原图与缩略图、独立分类/审核/用途/发布状态，SQLite 持久化和操作审计。
- **计划与预算**：默认暂停；单计划互斥；每次真实 HTTP 请求（含失败、robots、图片）前原子预留额度，按 UTC 日重置。速率和请求次数不冒充费用账单。
- **人工优先**：导入不自动授予权限；模型建议不自动审核。并发修改采用修订检查，旧建议不会覆盖新人工结果。
- **可选图文模型**：独立服务端配置、单图限长输入、持久队列、缓存、日额度和明确重试。默认关闭，无凭据时人工流程照常可用。
- **角色与会话**：viewer/operator/admin，服务端密码散列、HttpOnly 会话、CSRF 校验、限次登录；浏览器不持有管理员服务令牌。
- **交付与撤回**：明确选择素材，权限预检后生成 Ed25519 签名包；独立下游读取身份；永久签名撤回。保留 schema 1 / nova-1 协议，下游接收状态独立显示，未取得回执就是未确认。
- **迁移与恢复**：旧准备区只读迁入，历史图像与修订保留；备份完整性检查、恢复到新目录、计划暂停和会话失效。

## 快速开始

```powershell
git clone --branch variant/ad-workbench https://github.com/LazyS1a/OmniSignal.git
cd OmniSignal
uv sync --frozen --group dev
cd frontend
npm ci
npm run build
cd ..
$env:PYTHONPATH = 'src'
uv run python -m omnisignal.workbench init --root data/ad-workbench --username admin
.\scripts\start-ad-workbench.ps1 -EnableWorker
```

打开 `http://127.0.0.1:8503/workbench/`，用初始化命令生成的私有登录文件登录。创建计划不会立即采集，明确恢复后才运行。部署、模型配置、签名包读取、备份和角色创建见[运行说明](docs/ad-workbench-operations.md)。

## 验证方式与边界

```powershell
uv sync --frozen --group dev --extra ui --extra crawl
uv run pytest -q
cd frontend
npm ci
npm run build
```

离线测试覆盖导入/审核持久化、权限与CSRF、并发预算、暂停/重启、旧库迁入、模型超时/缓存/人工版本冲突、签名发布/撤回和备份恢复。浏览器验收使用明确标注的合成图片测试交互，真实广告来源单独验证，不把合成图当广告相关性评测样本。

完整计划中的50张真实标注样本、两类分别90%相关性目标、实际付费模型质量和独立消费方接收回执，仍需取得对应证据。当前自动广告源覆盖户外静态广告，并未实现全平台广告抓取。

源码与测试可以复用；生产图片、抓取正文、账号凭据、部署地址及私有业务代码不随本分支公开。原版通用修复可单独回馈 main，广告专用界面与分类保持在本变体。
